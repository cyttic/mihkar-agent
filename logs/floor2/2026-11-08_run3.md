## Request
Check the following three research questions and hypotheses. Check each one separately.

Question 1: Is there a relationship between developers' trust in AI code assistants and how much AI-generated code they check, among professional developers in Israel?
Hypothesis 1: Developers with higher trust check less AI-generated code. Null hypothesis: there is no relationship between trust and checking.
Definitions: trust is a score on a trust questionnaire. "Check" means reading the code line by line or running tests on it before merging, reported as a percentage of the AI code they receive.

Question 2: Does an "AI-generated" label change the number of defect comments professional developers write in a code review?
Hypothesis 2: Reviewers write more defect comments when the code is labelled as AI-generated. Null hypothesis: the label does not change the number of defect comments.
Definitions: all reviewers get the same code; half of them, chosen at random, see the label. A defect comment points to a bug or a security problem.

Question 3: Is there a difference in accessibility violations between web forms written by AI code assistants and web forms written by professional developers?
Hypothesis 3: AI-generated web forms have more accessibility violations. Null hypothesis: there is no difference.
Definitions: a violation is a WCAG 2.1 AA error found by an automated checker, counted per form. Both sources build forms from the same specifications.

Hypothesis type: causal. A causal hypothesis is valid only if the design can establish causality.
- **Stated in the definitions:** the label is manipulated, assignment is random, and all reviewers get the same code.
- **Not stated:** that the other half sees no label, and that reviewers do not know what is being tested. Both must be specified in planning.
- On these conditions, the design can in principle support the causal hypothesis.

Example refuting result: the labelled group writes the same number of defect comments as the unlabelled group, or fewer.

Warning on classifying text: whoever decides what counts as a "defect comment" can introduce bias. I suggest checking a sample of the classified comments by hand, ideally by a second person.

**Verdict: valid**
**Fix first:** state who classifies the comments and how, and state that the control group sees no label.
