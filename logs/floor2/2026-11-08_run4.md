## Request
Check the following research questions and hypotheses. Check each one separately.

Question 1: Is developers' trust in AI related to how much of its code they check?
Hypothesis 1: Developers who trust AI more check less of its code. Null hypothesis: trust and checking are not related.
Definitions: developers are professional developers in Israel (paid, at least one year of experience) who use AI code assistants. Trust is a score on a trust questionnaire. "Check" means reading the code line by line or running tests on it before merging, reported as a percentage of the AI code they receive.

Question 2: Do reviewers report a different number of defects when code is labelled as AI-generated?
Hypothesis 2: Reviewers report more defects when the code is labelled as AI-generated. Null hypothesis: the label does not change the number of defects reported.
Definitions: reviewers are professional developers. All reviewers get the same code; half of them, chosen at random, see the label, and the other half see no label. Reviewers are not told what is being tested. A reported defect is a review comment that points to a bug or a security problem, classified by two raters independently.

Question 3: Is AI-written web code more or less accessible than code written by developers?
Hypothesis 3: AI-written web code has more accessibility violations than developer-written code. Null hypothesis: there is no difference.
Definitions: web code means web forms built from the same specifications by AI code assistants and by professional developers. Accessibility is measured by the number of WCAG 2.1 AA violations found by an automated checker, per form.
